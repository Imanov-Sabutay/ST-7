# Отчёт по лабораторной работе ST-7

## 1. Цель работы

Обращение к веб-приложениям из программы на Java с использованием Selenium WebDriver: загрузка страниц в браузере, извлечение данных с HTML и из JSON.

## 2. Средства

Java 11, Maven, Selenium Java 4.15.0, json-simple 1.1.1, Google Chrome, chromedriver.

Классы: `App`, `Task2`, `Task3`.

## 3. Реализация

**Задание 1.** `System.setProperty("webdriver.chrome.driver", …)`, `ChromeDriver`, URL `https://www.calculator.net/password-generator.html`. Пароль — элемент `#resultid .verybigtext b`, вывод в консоль.

**Задание 2.** URL `https://api.ipify.org/?format=json`. JSON из `pre`, поле `ip`, вывод в консоль.

**Задание 3.** API Open-Meteo, координаты 56°N, 44°E. Таблица по `hourly.time`, `hourly.temperature_2m`, `hourly.rain`; вывод в консоль и файл `result/forecast.txt`.

# Отчёт: ST-7. Работа с веб-приложениями (Java, Selenium)

**Тема:** автоматизация обращения к веб-ресурсам через Selenium WebDriver, разбор JSON-ответов.

**Цель:** открыть заданные URL в браузере под управлением программы, извлечь пароль с HTML-страницы, IPv4 и почасовой прогноз погоды из JSON, вывести результаты в консоль; таблицу прогноза сохранить в `result/forecast.txt`.

---

## Средства реализации

| Компонент | Версия / сведения |
|-----------|-------------------|
| JDK | 11 |
| Сборка | Maven, `groupId` `com.mycompany.app`, `artifactId` `my-app` |
| Selenium | `selenium-java` 4.15.0 |
| JSON | `json-simple` 1.1.1 |
| Браузер | Google Chrome (канал Stable) |
| Драйвер | chromedriver (Chrome for Testing), путь задаётся в `System.setProperty("webdriver.chrome.driver", …)` |

Точка входа: `com.mycompany.app.App`. Задание 2 — класс `Task2`, задание 3 — `Task3`.

---

## Выполнение и результаты

### Задание 1

- Ресурс: `https://www.calculator.net/password-generator.html`.
- Пароль читается из DOM: селектор `#resultid .verybigtext b`, ожидание появления блока `#resultid`.
- Результат: строка пароля выводится в стандартный вывод (значение меняется при каждом запуске из-за логики сайта).

### Задание 2

- Ресурс: `https://api.ipify.org/?format=json`.
- Тело ответа читается из элемента `pre` (при отсутствии — из `body`), разбор через `JSONParser`, поле `ip`.
- Результат: IPv4-адрес выводится в консоль строкой.

### Задание 3

- Данные: API Open-Meteo, координаты Нижнего Новгорода 56°N, 44°E; запрос с параметрами `hourly=temperature_2m,rain`, `timezone=Europe/Moscow`, `forecast_days=1`, `wind_speed_unit=ms`, `current=cloud_cover`.
- Из JSON извлекаются массивы `hourly.time`, `hourly.temperature_2m`, `hourly.rain`; формируется таблица с колонками: №, дата/время, температура, осадки (мм).
- Результат: таблица печатается в консоль и записывается в **`result/forecast.txt`** (кодировка UTF-8).

Фрагмент сохранённой таблицы (файл в репозитории на момент фиксации отчёта):

```
№   	Дата/время         	Температура 	Осадки (мм)
1   	2026-05-16T00:00   	16.1        	0.0
2   	2026-05-16T01:00   	15.9        	0.0
…
24  	2026-05-16T23:00   	18.3        	0.0
```

Полный перечень строк — в `result/forecast.txt`.
